<h2>1. Использование конвейеров и первого конвейера</h2>
<pre>
На самом деле концепция проста. Конвейеры и перенаправление используются для отправки (или получения) информации, 
переданной от одной команды или скрипта к другой команде или скрипту. Это работает и с файлами. 
Давайте рассмотрим несколько примеров:
<ul>
  <li>Подсчитать количество строк в файле</li>
  <li>Выбрать уникальные значения из одного файла и записать их в другой</li>
  <li>Найти в файле или системе вхождения какой-либо строки</li>
</ul>

Конвейер |
Наша первая структура — это конвейер, в котором используется |.

Структура выглядит так:

command1 | command2

command1 | command2 | command3

Да, мы можем комбинировать столько конвейеров, сколько захотим.

Как это работает? Вывод command1 используется в качестве ввода для command2. 
И этот процесс может продолжаться до следующей команды.

<details>
<summary>Вопрос 3: У меня есть файл, в котором каждая строка содержит одно слово. 
          Я хочу узнать, сколько уникальных слов в файле. 
          Какая команда справится с этой задачей?

1) cat file | sort | wc -l
2) cat file | sort | wc -l | uniq
3) cat file | uniq | sort | wc -l
4) cat file | wc -l | uniq | sort
5) cat file | sort | uniq | wc -l <br>
</summary><br><b>
Ответ: Вариант 5
</b></details>
