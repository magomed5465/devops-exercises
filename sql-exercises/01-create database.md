Шаг 7. Выбирию наиболее подходящий формат данных для каждой колонки. Используя комментарий (-- comment), для каждого поля пишу, почему выбрал тот или иной тип данных. Например:
brand_name varchar(50) — не существует названий брендов длиной более 50 символов, в названии бренда могут быть и цифры, и буквы, поэтому выбираем varchar(50).
price numeric(9, 2) — цена может содержать только сотые и не может быть больше семизначной суммы. У numeric повышенная точность при работе с дробными числами, поэтому при операциях c этим типом данных, дробные числа не потеряются.

Задание 2

Задание 3

Задание 4

Название машины показываю полное, с названием бренда — например: Tesla Model 3. Сортируйте по имени пользователя в восходящем порядке. Сортировку внутри самой строки с машинами не делаю.
Задание 5
Пишу запрос, который вернёт самую большую и самую маленькую цену продажи автомобиля с разбивкой по стране без учёта скидки. Цена в колонке price дана с учётом скидки.
Задание 6
